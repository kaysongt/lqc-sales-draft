# Latin Quarter Collective client preview

Cozy Digital's client-review draft, hosted at https://kaysongt.github.io/lqc-sales-draft/ from `main` and the repository root.

Static HTML/CSS/JavaScript. No build step. Serve locally with `python3 -m http.server 8000`.

Includes a responsive editorial homepage, self-hosted fonts and photography, an accessible case-study dialog, service disclosures, mobile navigation and two inquiry paths. The inquiry form prepares a copyable draft only. It does not transmit, store or claim to receive inquiries. Production delivery requires an approved destination and privacy language.

Existing `contact.html`, `partner.html` and main anchors remain supported. Search indexing stays disabled for this review site.

See `ASSET_SOURCES.md` for asset provenance and final approval items. Private meeting preparation is not stored in this public repository.
